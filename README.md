# Kuantum Çorap Kaybolma Makinesi

## Bilimsel Giriş (Ciddiye Alınız)

Bu proje, çamaşır makinesi ile çorap arasındaki gizemli ve açıklanamayan ilişkiyi kuantum mekaniği, kaos teorisi ve tamamen uydurulmuş formüllerle modellemektedir. 

Yıllardır bilim dünyasının görmezden geldiği bir gerçek var: Çoraplar kaybolur. Bu kaybolma rastgele değildir. Makinenin yaşı, attığınız çorap sayısı ve o günkü şans katsayınız doğrudan etkiler.

### Kullanım

```bash
python corap_kaybolma.py
```

Soruları cevaplayın. Makine size gerçeği söyleyecektir. (Gerçek değil ama)

### Formül

```
P = (Çorap Sayısı × π) / (Makine Yaşı + 1) × Şans × Kuantum Kaos
```

Bu formül Nobel ödülüne aday gösterilmemiştir. Henüz.

### Uyarı

Bu yazılım çorabınızı geri getirmez. Sadece kaybolacağını söyler. Sorumluluk kabul edilmez.
